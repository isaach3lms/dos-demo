# Discipleship Operating System — Client Demo

Interactive, click-through mockup used in sales conversations with churches and nonprofits.
Single static HTML file. No build step, no dependencies, no data collection.

## Contents
- `index.html` — the full demo (staff view, member app, talk track)
- `robots.txt` — blocks search indexing

## Run locally
Open `index.html` in any browser.

## Deploy on Render
New > Static Site > connect this repo.

| Field | Value |
|---|---|
| Branch | main |
| Root Directory | (blank) |
| Build Command | (blank) |
| Publish Directory | . |

## Demo flow
1. Journey rail: ask the pastor how many people are stuck between Guest and Attender.
2. Click Marcus Webb: 43 days as a Guest, no contact in 3 weeks.
3. Tyler Brooks: automated welcome sequence, no staff time.
4. Switch to Member app.
5. Settings: change the brand color, prove white label.
6. Settings: cost comparison. Verify the line items against the church's real bills first.

Open the "Talk track" button in the top right for the full script.

## Before each demo
Update the church name, city, and cost line items for the specific prospect.
Fabricated data. Not for public promotion.
